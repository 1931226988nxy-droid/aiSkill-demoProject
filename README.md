# 云澜图书馆管理系统

一套可运行的图书馆业务系统，覆盖图书编目、馆藏副本、检索、借阅、归还、续借、预约、逾期费用、读者管理、通知公告、统计报表、角色权限与审计日志。

系统同时支持**一人多角色、运行中切换角色、数据库驱动的权限与导航菜单、按分组展示的模块工作区**。

前端沿用当前工程的 **Vue 3 + Vite + Ant Design Vue**，并复用 `@jcc/shared` 已公开的 `JccProvider`、`JccAppShell`、`JccPagePanel`、`JccQueryBar`、`JccTable`、`JccFormModal`、`useTableQuery`、`createHttpClient`、`formatDate` 等能力。

后端采用 **Node.js 内置 `node:sqlite` + Express 5**，不依赖外部数据库服务；开发模式下 Express 同时托管 API 与 Vite 中间件，只启动一个进程即可访问完整系统。

## 快速开始

环境要求：**Node.js >= 22.20.0**（使用内置 SQLite 和在线备份 API；启动脚本已添加 `--experimental-sqlite`）。

```bash
npm install
npm run dev
```

公共组件库 `@jcc/shared` 的唯一维护目录是仓库内的 `packages/shared`，由 npm workspaces 和根锁文件统一管理。请在仓库根目录安装依赖；本项目不依赖其他本机目录。业务接口、权限、路由和产品信息由应用维护，产品文案集中在 `src/site-config.js`。

访问 <http://localhost:3000>。开发模式首次启动会自动执行迁移并写入演示数据。

## 页面滚动结构

- 桌面端：Header 与左侧导航固定，应用壳层高度锁定为视口；页面本身不产生整页滚动。
- 工作台：内容区统一滚动，统计卡和业务卡片随内容自然排布；窗口变窄时快捷入口自动减少列数。
- 列表页：查询条件与分页固定，表格内容区纵向/横向滚动，表头吸顶。
- 详情、个人资料、设置、报表等长内容页：右侧内容面板统一滚动，页头保持固定。
- 左侧菜单在屏幕高度不足时只在菜单区域内部滚动。
- 移动端：恢复自然页面滚动，左侧导航切换为抽屉，避免固定高度与软键盘冲突。

这套行为集中由 `src/components/PageBody.vue` 与 `src/assets/main.css` 的壳层覆盖样式实现，没有修改 `@jcc/shared` 源码。

## 动态权限、菜单与多角色

### 角色与菜单

- 一个账号可以分配多个角色，但至少保留一个角色；可指定一个主角色。
- 登录后默认使用主角色；右上角账号菜单可以切换当前角色，角色标签会同步变化。
- 当前角色的权限决定菜单、页面路由、按钮和后端接口校验结果；切换角色后导航与权限即时刷新。
- 菜单结构为“模块 → 标签分组 → 功能菜单”。例如“馆藏综合”模块下可以有“检索与借阅”“馆藏运维”等分组。
- 点击模块后进入模块工作区，每个分组独立展示标题、说明和功能卡片，点击功能卡片进入具体页面。
- 模块工作区通过左侧导航切换；功能页面可返回所属模块。
- 菜单、权限、角色和用户关系均保存在数据库中；默认菜单由迁移/种子初始写入。
- 新增权限或菜单后，会出现在“权限与菜单”管理页和角色权限矩阵中。
- 菜单新增时可直接填写新的权限编码，保存时自动创建权限。

### 新增功能的流程

1. 开发并部署新的 Vue 页面和对应的后端接口（页面必须注册路由）。
2. 在“权限与菜单 → 权限管理”新增接口权限，或在新增菜单时直接填写权限编码自动创建。
3. 在“菜单管理”新增模块、标签分组和功能菜单，功能菜单选择已注册的路由路径和绑定权限。
4. 在“账号与角色”中给角色授权，并把角色分配给用户。
5. 对应用户切换角色后即可在导航中看到新模块/功能。

菜单路径会校验是否为当前工程已注册的静态路由；不能通过后台配置凭空生成一个不存在的业务页面。

## 权限与安全

- 17 个内置权限码 + 可扩展的数据库权限；读者/馆员/管理员内置角色。
- 多角色、主角色与当前激活角色；当前角色权限决定接口和导航，切换角色后立即生效。
- 委派了账号管理权限的馆员不能分配管理员角色、修改管理员账号或授予超出自身的权限。
- 前端菜单由 `/api/navigation` 按当前角色权限返回，菜单、页面路由、按钮均按权限控制；**后端每个敏感接口独立校验权限**。
- 读者只能访问自己的借阅/预约/费用；续借与取消预约在服务层校验归属。
- 密码使用 Node `scrypt` + 随机盐哈希，数据库不保存明文。
- 会话使用随机令牌，数据库只保存 SHA-256 哈希；Cookie 为 `HttpOnly`、`SameSite=Strict`，生产强制 `Secure`。账号停用撤销会话，空闲 30 分钟失效。
- 读者列表手机号/身份证脱敏；图书详情不暴露借阅人信息；读者完整资料仅 `reader.manage` 可见。
- 所有 SQL 使用参数绑定；排序字段使用白名单；服务端统一字段校验。
- 借还、续借、预约流转、费用处理使用事务；部分唯一索引和条件更新保证并发下不重复借出/预约。
- 审计日志只读，不提供修改或删除接口。

## 时区与金额

- 数据库统一存 UTC ISO 时间；界面按 `Asia/Shanghai` 展示。
- 应还日期与预约取书期限为上海时区当日 23:59:59.999。
- 统计日期范围按上海自然日切分。
- API 金额为元，数据库以分存整数，避免浮点误差。

## 数据库与重置

默认数据库：`data/library.db`。可通过 `DB_PATH` 覆盖。

重置演示数据（停止服务后）：

```bash
# Windows PowerShell
Remove-Item data\library.db
npm run dev
```

迁移文件位于 `server/db/migrations/`，启动时自动执行。

## 环境变量

复制 `.env.example` 为 `.env` 并按需设置；启动脚本使用 Node 的 `--env-file-if-exists=.env` 加载，也支持直接设置进程环境变量。

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `3000` | HTTP 端口 |
| `HOST` | `0.0.0.0` | 监听地址 |
| `DB_PATH` | `data/library.db` | SQLite 文件 |
| `COOKIE_SECURE` | 开发 `false`，生产 `true` | 生产禁止显式关闭 |
| `NODE_ENV` | 开发 | `production` 时读取 `dist/` |
| `INITIAL_ADMIN_USERNAME` | `admin` | 生产环境空库首次启动的管理员账号 |
| `INITIAL_ADMIN_PASSWORD` | 无 | 生产环境空库首次启动必填；使用独立强密码 |

## 生产部署

```bash
npm install
npm run build
# 在 .env 中设置独立的 DB_PATH 和 INITIAL_ADMIN_PASSWORD
npm start
```

`npm start` 使用 `--production` 模式提供 `dist/` 静态文件与 `/api` 接口。必须显式配置独立 `DB_PATH`，通过 HTTPS 访问，并设置 `COOKIE_SECURE=true`。空库只创建初始管理员，密码至少 12 字符，默认关闭自助注册。

生产启动会拒绝演示数据库和已知演示口令。备份恢复、监控、升级说明及需要外部配置的事项见 [生产说明](docs/PRODUCTION.md)。

## 已知边界

- 系统不提供在线支付：费用仅支持线下处理（`settled`）或豁免（`waived`），没有伪造支付回调。
- 当前没有既有邮件/短信服务，因此只发送站内通知；`NotificationService` 已提供外部适配器接口，接入真实服务时注入实现即可。
- 封面仅保存 URL，不支持对象存储上传；无封面时使用系统生成的占位封面。
- SQLite 适合当前单实例部署；多实例横向部署应迁移到 PostgreSQL/MySQL 等服务型数据库。
- 项目使用 JavaScript（ESM），已配置 ESLint、业务回归、公共组件测试、Playwright 浏览器回归和 GitHub Actions。
